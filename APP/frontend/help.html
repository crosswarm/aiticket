欢迎使用 AI 工单智能助手 👋

这套系统把你的 Jira 工单接进来，用 AI 帮你分类、找相似历史案例、起草回复。 新账号刚登录时看板可能是空的 —— 那是正常的，因为还没把你的 Jira 账号绑上去。 照着下面三步走完，大约 3 分钟就能开始干活。

3绑定 Jira 会话（最关键的一步）

系统需要用你自己的 Jira 身份去读工单，所以要把浏览器里已登录的会话交给它。 最省事的做法是复制一条 cURL 命令粘进来 —— 里面该有的信息全都有，系统会自动解析。

为什么推荐「复制 cURL」？ 因为这一步会同时带上 JSESSIONID、 atlassian.xsrf.token 和你公司 Jira 的网址， 三样东西一次全自动提取，你不用一个个手抄，也不用手填地址。
  1. 用 Chrome 打开公司 Jira，正常登录完

    如果有短信 / 令牌等二次验证，走完整个流程，确认能正常看到工单页面。 没登录成功就复制，拿到的是一个空会话，后面一定失败。

  2. 按 F12 打开开发者工具，切到 Network（网络）面板
  3. 按 F5 刷新一次页面

    刷新后 Network 列表里会刷出一堆请求，这是正常的。

  4. 在任意一条请求上右键 →「复制」→「以 cURL 格式复制」

    英文界面是 Copy → Copy as cURL。别选成旁边的 「以 PowerShell 格式复制」或「以 fetch 格式复制」，那两种格式本平台解析不了。

  5. 回到本平台，打开账号设置

    点右上角你的头像 → 账号设置，找到「🔑 Jira 账号绑定」， 认证方式保持默认的 浏览器 Session（推荐）。

    直接打开账号设置 →
  6. 点「📋 粘贴 cURL 导入」，整段粘贴，再点「🧪 解析并保存+测试」

    整段粘贴就行，不用挑内容、不用删东西。

  7. 看到「✅ 绑定成功！Jira 连接 OK」就完成了

    页面会在 3 秒后自动刷新并开始加载工单数据。

手动填写（备选方案）

如果不方便复制 cURL，也可以手工填：F12 → Application → 左侧 Cookies → 选你的 Jira 域名 → 找到 JSESSIONID，复制它的值粘到输入框； 有 atlassian.xsrf.token 的话一并填上（可选）。这种方式需要你自己在 「Base URL」里填公司 Jira 的网址。

关于安全和有效期

  • 你的会话信息是加密后存在服务端的，并且只对你自己的账号生效，其他人看不到、也用不了。
  • Jira 的会话过几天会自然过期。等到看板突然没数据、或提示 401 未授权时， 把上面第 1～7 步再做一遍就行，大约 10 秒。
如果提示「无法解析域名」，那不是会话过期，而是网络问题：请确认填进去的 Jira 地址是对的， 并且这台服务器本身能访问到它（内网 Jira 通常要接入公司网络）。

4绑定 PM 系统（用到 PM 看板才需要）

方法和 Jira 完全一样，只是换个网站复制。

  1. 用 Chrome 打开并登录 PM 系统
  2. F12 → Network → F5 刷新 → 右键任意请求 → Copy as cURL
  3. 账号设置 → 「🔑 PM 系统绑定」→ 点「📋 粘贴 cURL 导入」→ 整段粘贴

    系统会自动提取 yht_access_token 和全部 ycap_* 凭据， 并显示这次会话的有效期。

只用工单看板、不用 PM 看板的话，这一步可以跳过，不影响其它功能。

5默认项目、切换项目、查看全部项目

这里有两个入口，作用不一样，容易混，先分清楚。

入口作用影响范围
账号设置
默认项目与关注模块		 设定你每次登录后默认看到的项目和模块 跟着账号走，换电脑也生效
顶栏「作用域」 临时切到别的项目看一眼，不改默认设置 只影响当前这台浏览器

设定默认项目（推荐先做）

  1. 头像 → 账号设置 → 找到「🏷️ 默认项目与关注模块」
  2. 在「默认项目」框里搜项目名或项目编码，点选中
  3. 按需勾选「关注领域模块」，然后点「保存默认范围」

    模块一个都不选就代表全部模块，不用担心漏掉。

临时切换项目 / 查看全部项目

页面右上角有一个作用域按钮，上面写着当前范围（形如 ABC · 全部模块）。 点它 → 搜索并选择项目 → 点「应用」即可。

想跨项目一起看，就在项目列表里选 全部项目。

第一次进某个项目时看到「索引中」是正常的。 系统正在为这个项目的历史工单建立语义索引，建好之后相似工单推荐才准。 等进度走到 100% 就行，中途可以先去干别的。

6配置你自己的大模型 API Key

AI 分析、智能回复、知识库问答都要调用大模型。这里配的是你的个人 Key，只对你生效， 不会影响其他同事。（管理员另外有一套系统级配置作为兜底。）

也可以随时从左侧栏底部的「AI 配置」进入。

  1. 选择 Provider（模型厂商）

    下拉里有 zhipu、aliyun、deepseek、 minimax、kimi、openai、gemini、 local 等。用哪家就选哪家。

  2. 填 API Key

    Base URL 一般留空就行，留空表示用该厂商的官方地址。 只有当你走的是自建网关或第三方中转（OpenAI 兼容接口）时，才需要填。

  3. 点「保存源凭据」

    这一步只保存 Key 和地址。模型要在下一步单独添加。

  4. 在下方「模型」区添加模型名，并选中要用的那个

    输入模型名（例如 glm-4.5、qwen-max、 deepseek-chat）回车或点「添加模型」。 一个源下可以放多个模型，被选中的那个标着「生效」，你所有 AI 功能都会用它。

  5. 点「测试连接」确认可用

    看到成功提示就配好了，可以直接回看板用。

顺序别搞反：必须先「保存源凭据」，才能添加模型。 没保存 Key 就加模型，界面会提示你先保存凭据。

7AI 是怎么学会你的写法的

智能回复不是一成不变的模板。你每改一次它的草稿，它就学一次。 用得越久，起草的内容越像你自己写的。

它是这样学的

  • 你在回复编辑器里改完 AI 草稿、点「提交处理」，系统就把 AI 原稿 + 你的最终定稿一起存成一条范例。
  • 系统会按你改动的幅度自动判档：几乎没改 = 直接采纳，改了一部分 = 加工处理， 推翻重写 = 未采纳。这个判断是自动的，你不需要手工标注。
  • 下次遇到类似的工单，系统会先把你过去处理同类问题的定稿找出来作为参考喂给模型， 再叠加从你历史修改里提炼出的风格规则（比如你习惯的开头语、结构、措辞禁忌）。

怎么确认它真的在学

打开任意工单的回复编辑器，展开下面的「生成详情」折叠区，看这两行：

  • 回复范例 —— 这次生成参考了你过去多少条定稿。
  • 风格规则 —— 这次生成套用了哪些从你习惯里提炼出来的规则。
两种做法会让它学不到东西：

① 嫌麻烦，草稿不改直接发 —— 系统会以为这就是你想要的，把问题一并学走；

② 把草稿复制到别处改好，再贴回来发 —— 系统看不到你的修改过程。

正确做法是：就在回复编辑器里改，改完点「提交处理」。这是它变聪明的唯一入口。

8回复或推荐不对？一键上报

AI 偶尔会推荐一个完全不搭边的历史工单，或者回复跑偏。 遇到了别忍着 —— 上报一下，系统会立刻把这个错误案例记下来并避开，不用等管理员处理。

方式一：随手上报（推荐）

  1. 点右下角的 📝 浮动按钮，或直接按 ⌥N（Windows 是 Alt+N）
  2. 切到 🔴 Badcase 标签页
  3. 填三个格子，然后 Ctrl+Enter 或点「提交 Badcase」
    • 工单号或标题 —— 出问题的那张工单；
    • 问题点 —— 哪里不对，说人话就行；
    • 期望效果 —— 你觉得应该是什么样（可以不填，但填了更有用）。

方式二：精准标掉一条错误推荐

打开回复编辑器 → 展开「生成详情」→ 找到 G3 历史复用 里的「主复用工单」， 它旁边有一个「不该推荐」按钮。觉得这条历史工单跟当前问题八竿子打不着，点一下即可。

多久生效？立刻。 上报之后，这条错误配对会马上写进屏蔽名单：同一张工单不会再推荐它， 语义上相近的工单也会降低它出现的概率。不需要重启，不需要等管理员审核， 下次刷新就见效。

小提示：为了防误触，同一张工单 5 分钟内最多上报 10 次，超过会提示稍后再试。

9常见问题

遇到问题先看这里，大部分能自己解决。

看板是空的，或者提示 401 / 未授权

九成是 Jira 会话过期了。回到第 3 章，把复制 cURL 那一套重做一遍， 10 秒就好。

如果提示的是「无法解析域名」，那是网络问题不是会话问题：确认 Jira 地址填对了， 并且当前网络能访问到它。

项目一直显示「索引中」，进度不动

首次为一个项目建立语义索引需要几分钟，工单越多越久，期间可以先做别的事。

如果超过半小时还停在同一个进度，说明索引任务可能中断了，联系管理员处理。

点 AI 分析没反应，或提示未配置模型

你的个人大模型配置还没填好。见第 6 章， 注意要先「保存源凭据」再添加模型，并把要用的模型选中为「生效」。

配完记得点一下「测试连接」，确认 Key 本身是通的。

AI 起草的回复不像我们的口径

这是正常的冷启动阶段 —— 它还没见过你怎么写。 坚持在回复编辑器里改草稿再提交，用上十几单之后会明显贴近你的风格。 原理见第 7 章。

如果是推荐了不相关的历史工单，直接按第 8 章上报，立刻生效。

我想换个默认项目 / 想同时看多个项目

换默认：账号设置 →「默认项目与关注模块」。临时看别的：顶栏作用域按钮。 想跨项目看：作用域里选「全部项目」。详见第 5 章。

忘记密码 / 想改密码

改密码：左侧栏「账号与用户」→「修改登录密码」。改完会退出登录，用新密码重新登录即可。

忘记密码：找管理员在「账号与用户」页面帮你重置，会生成一个一次性临时密码。

PM 看板打不开 / 没数据

需要单独绑定 PM 系统会话，见第 4 章。 PM 会话同样会过期，过期后按同样方法重新导入一次。
